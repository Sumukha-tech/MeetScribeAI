# MeetScribeAI

MeetScribeAI is an AI-powered meeting assistant designed to transcribe, summarize, and extract actionable insights from video conferences and meetings in real time.

## Features

- 🎙️ **Real-Time Audio Transcription**: Accurately transcribes live meeting audio into clean text.
- 📝 **Automated Summarization**: Generates concise meeting summaries and key takeaways automatically.
- 📌 **Action Item Extraction**: Identifies and organizes follow-ups, tasks, and assigned owners.
- 🔍 **Searchable Transcripts**: Easily search through past meeting notes and logs.

## Tech Stack

- **Frontend**: React / Next.js
- **Backend**: Node.js / Express or Python (FastAPI)
- **AI Models**: OpenAI Whisper (Speech-to-Text), GPT API / LLM (Summarization)
- **Database**: PostgreSQL / MongoDB
